How the calculation works

Monthly consumption (kWh) = appliance watts × daily usage hours × days in month ÷ 1000.

The displayed amount is an energy-charge estimate using the supplied tariff data. Unknown fixed charges, duties, subsidies, and other adjustments are shown as unavailable, not treated as zero. Tamil Nadu uses a two-month tariff estimate, with a monthly-equivalent amount used for the monthly budget comparison.
